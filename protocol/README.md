## Contents

- experiment_protocol.md: frozen event, policy, and statistical-unit definitions.
- instance_manifest.csv: instance filenames, scales, split roles, and SHA-256 hashes.
- checkpoint_manifest.csv: checkpoint filenames and SHA-256 hashes.
- upstream_file_provenance.csv: unchanged matches to the audited upstream snapshot; no match does not prove original authorship.
- file_manifest.sha256: checksums of all package files except the manifest itself.
- availability_placeholders.md: retained legacy filename containing current access and license-confirmation status.
