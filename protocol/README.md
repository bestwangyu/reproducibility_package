# Experimental protocol and file metadata

**Article:** Graph reinforcement learning for dynamic flexible job shop scheduling under composite disturbances with a schedule-stability budget

**Journal:** The International Journal of Advanced Manufacturing Technology

**Authors:** Yu Wang (1, corresponding author), Xiaoyao Ding (1)

1. School of Information Engineering and Artificial Intelligence, Henan Open University, Zhengzhou 450046, China

**Correspondence:** Yu Wang, affiliation 1; wangyu@haou.edu.com

## Contents

- experiment_protocol.md: frozen event, policy, and statistical-unit definitions.
- instance_manifest.csv: instance filenames, scales, split roles, and SHA-256 hashes.
- checkpoint_manifest.csv: checkpoint filenames and SHA-256 hashes.
- upstream_file_provenance.csv: unchanged matches to the audited upstream snapshot; no match does not prove original authorship.
- file_manifest.sha256: checksums of all package files except the manifest itself.
- availability_placeholders.md: retained legacy filename containing current access and license-confirmation status.
- REPRODUCTION.md: complete independent-test, ablation, development and statistics commands.
- independent_test_v1.json: unchanged original independent-test data/model/code lock; historical model paths are mapped by verify_reproduction_inputs.py.
- REVISION_VALIDATION.md: checks performed on the v1.0.1 reproduction-entry revision.
