# Author actions before public deposit

Replace the following placeholders before submitting the package to a public repository:

1. `REPOSITORY_URL_OR_DOI`: permanent GitHub release, Zenodo DOI, or institutional repository record.
2. `LICENSE`: confirmed code and data license.
3. `AUTHOR_NAMES`: final author list if the repository is not anonymous for review.
4. `DATA_REUSE_PERMISSION`: confirmation that the FJSP instances and checkpoints may be redistributed.
5. `RELEASE_TAG`: immutable version corresponding to the submitted manuscript.
